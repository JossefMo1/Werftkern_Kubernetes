# Werftkern v0.1.0-alpha.2 — experimental source-only alpha

**PRIVATE experimental pre-release · NOT_PRODUCTION_READY · no CNCF certification.**

This development source release follows the original private
`v0.1.0-alpha.1`. It is created automatically only after all three
defined GitHub CI workflows succeed for the same current `main` commit.
It distributes GitHub-managed source archives only: **no executable
packages, unsigned binary artifacts, production signatures, or
reliability guarantees**.

## Changes since alpha.1

- Corrected the canonical Go module identity from the original
  `github.com/ClusterPilot-System/werftkern` to this repository's
  `github.com/JossefMo1/Werftkern_Kubernetes` path.
- Updated Go package imports, the native package build's linker
  variable paths, and development/publishing documentation.
- Added a regression test enforcing module-path consistency.

## What is included

- The experimental k0s/k0sctl-based Kubernetes management path
  (source component version `0.1.0-dev.3`).
- The independent experimental Go Native Runtime
  (source component version `0.2.0-dev.4`).
- Source, test suites, security policies, and CI/publication guards.
  No standalone `kubectl`, k0s binaries, Helm charts or Sonobuoy
  distributions are embedded by this source release.

## Important release boundaries

- CI/source scans and fixture-based contract tests are **not** real
  multi-host Kubernetes qualification or a security/IP assessment.
- Native dev.3-to-dev.4 binary upgrade compatibility remains
  **BLOCKED/UNVERIFIED**, because the historical dev.3 source commit
  is not available in this repository (issue #8).
- GitHub server-side branch protection remains an independent
  blocker while the required private repository plan/organization
  permissions are absent (issue #7).
- No new actual HA-chaos, fencing, CSI/PV restore, PostgreSQL PITR,
  real SSO, cert-manager ACME, Sonobuoy Certified Conformance,
  cloud infrastructure, load/soak or external security review is
  claimed.
- Do not use on production clusters, customer workloads or
  untrusted tenants. Not a certified Kubernetes distribution.

The earlier alpha.1 tag is an immutable historical snapshot and
continues to contain its original Go module path. Do not retag or
rewrite it to conceal that difference.
