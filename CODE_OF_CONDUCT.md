# Code of conduct

Participants in issues, pull requests and project discussions should be
respectful, constructive and considerate of different experience levels.
Critique code and ideas with evidence. Keep disagreements focused on the work.

Harassment, threats, discriminatory abuse, sexual harassment, publication of
personal information without consent, and deliberate disclosure of credentials
or private security reports are unacceptable.

The repository owner and appointed maintainers may remove harmful content,
close disruptive discussions or restrict participation. They should explain
decisions where doing so does not expose private information. This policy does
not promise an independent moderation team or a response-time SLA.

Contact a maintainer through an available private channel to report a concern.
If no such channel is available, request private contact without posting
sensitive details, or use GitHub's abuse-reporting tools. Security
vulnerabilities follow [SECURITY.md](SECURITY.md).
